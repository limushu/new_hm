# 案笺视觉原则

2026-11-17 用户确认的长期方向：**克制、舒适、耐看，精致但不抢眼。** 案笺服务独立律师的持续工作，视觉质量来自清晰的内容秩序、一致的细节和顺畅的操作。本规范作为后续界面调整的全局基准，与[公共架构原则](../../AGENTS.md)共同执行。

## 内容与层级

首屏优先交代正在处理的案件、当前进度与需要关注的事情。标题、正文、元信息有稳定的阅读顺序；辅助操作退到次要位置，仍然容易发现。默认展示完成当前工作所需的信息，其余信息按需展开。

同一操作区域有一个主要动作，其余使用次要或文字样式。分区主要通过对齐与间距形成，边界只出现在需要识别独立对象或操作范围的位置。卡片高度跟随实际内容，列表节奏保持紧凑，分区之间保留呼吸空间。

## 色彩与表面

| 角色 | 规则 |
| --- | --- |
| 页面与阅读区域 | 中性底色，轻微明度差表达层次，深浅主题分别适配 |
| 主要动作与选中 | 少量使用同一自适应强调色，保持可辨识的前景对比 |
| 案件状态、期限与收支 | 保留业务语义，用小面积标记、文字或细边表达，并提供文字名称 |
| 卡片与工具栏 | 以安静、稳定的表面承载内容；色彩占比服从阅读层级 |
| 浮层与编辑面板 | 使用一致的边界和阴影层级表达浮起，保持背景内容与当前操作的关系清楚 |

强调色沿用 [themes.css](../../src/themes.css) 的同一色种与角色变量，随深浅主题派生。主按钮与选中文字达到至少 4.5:1 的对比度；保持主要内容清晰可读。状态和费用图表继续保留有用的区分。

## 比例与细节

- 字体使用[语义字号与字重](typography.md)：正文稳定、标题适度、元信息清楚；长标题通过布局容纳。
- 按钮沿用[共用组件和 44px 规格](buttons.md)，同级动作的名称、图标、尺寸与反馈一致。
- 小型选中标记与触控区域分别设计，例如日期的数字底色保持紧凑，整格仍可点击。
- 相关内容的间距较近，独立分区的间距较远；同类布局复用相同节奏，优先使用现有公共尺度。
- 动效用于解释状态变化，反馈及时；触控与键盘操作均有明确的焦点与选中状态。
- 编辑具有清楚的保存、取消和错误反馈，选择完成后自然收起菜单。

## 落地顺序与验收

调整从公共色彩、字体、控件和布局规则入手，再检查今天、案件列表、案件详情、材料、人员与费用页面。每轮以实际渲染的页面和虚构业务数据核对，保持已认可的工作路径。

截至 1.8.1（33.1），共用按钮、自适应强调色与紧凑日期标记已有实现。此次样式检查仍发现案件卡片有独立的渐变和侧边装饰，浮层也有多组独立阴影定义；这些属于后续统一表面层级的核对项，本次仅确立全局规范。

验收同时观察深浅主题、320/390/430px 手机及桌面、空态与内容较多的页面。检查阅读重点、对齐、密度、触控区域和文字对比；让主要内容在正常扫读中清楚呈现。浏览器预览与自动化用于布局和交互核对，签名真机另验证实际手感。

## 主页面页头

1.8.5 将今天、案件、联系对象、回收站及设置接入同一个 [PageHeader](../../src/components/PageHeader.tsx)，并由[公共样式](../../src/components/page-header.css)管理页面内边距、标题和说明文字。主页面统一纯文字标题；导航图标留在导航中，案件详情的书页标识保持原有语义。

手机页面顶部 16px、左右 18px，标题 24px / 600 / 1.25 行高；桌面标题 30px。标题行至少 44px，主按钮与这一行居中对齐，不随说明文字的行数偏移。数量、星期和辅助说明独占下一行，共用 13px 辅助文字样式。日历清单的月份日期作为标题、星期作为说明，320px 下仍保留完整日期和新建按钮。其他日历视图的切换与辅助操作放在标题行之后。

页面不得另外覆盖标题字号、图标或顶部留白。不同页面可以按内容选择说明与动作，但相同屏宽下应保持标题起点、字重、行高与主按钮规格一致。安全区由应用外壳处理，不在各页重复叠加。

2026-11-17 在 Chromium / WebKit、320 / 390 / 430 / 1280px、深浅两套主题下读取五页实际渲染坐标，共 80 组核对通过：同环境的标题起点、行高、字重相同，无标题图标及横向溢出；三个同级新建动作均为 112×44px、8px 圆角。以下原始预览使用虚构工作区，WebKit 390×844px、模拟 59/34px 安全区，包含浏览器预览横幅，不作为原生截图或 App Store 素材。

## 核心工作流程（1.8.8）

2026-11-19 用户同意沿“今天 → 案件列表 → 案件时间轴 → 对象详情”统一打磨。以[公共浮层](../../src/components/workspace.css)、[案件布局](../../src/features/cases/case-workspace.css)及已有字号、按钮、强调色变量作为入口，清理时间轴和补充样式中重复的页头、标签栏、当前关注定义。公共间距为 4 / 8 / 12 / 16 / 24 / 32px，卡片圆角 12px，按钮沿用 44px / 8px。

- 案件卡片先展示名称，状态与当前关注共用辅助行，保留标签和下一项工作；以轻微状态底色和边界表达差异。示例卡片从约 147px 收至约 116px，长名称按内容增长，不压缩或隐藏业务信息。
- 案件名称使用自动增高文本框，长名称完整换行；状态与标签在同一区域自然换行。保留明确保存、取消，失焦不自动保存名称。当前关注改为一条紧凑的节点入口，接下来工作沿用同一任务数据。
- 手机时间轴将日期移至内容上方，标题与正文使用剩余整行，菜单保留独立触控区域；桌面仍使用日期列。查看条目统一打开对象详情，原件预览保持已有明确入口。
- 详情、属性、关联与日程编辑共用浮层框架：桌面居中，手机贴底；背景覆盖手势区，操作避让安全区。顶部关闭、底部保存和取消固定，正文独立滚动。打开下一层编辑时仅显示当前浮层，取消后保留原对象上下文。
- [可见窗口协调](../../src/platform/viewport.ts)统一观察 VisualViewport，键盘出现后收缩浮层正文并将操作区移至可见区域；页面不各自计算键盘高度。保留缩放能力，缩放时维持正常布局，不跟着缩放重排浮层。

浏览器回归核对 320 / 390 / 430px、横屏、桌面及深浅主题，验证完整名称、数据保留、固定操作、正文滚动和取消返回。新增 iOS 实际应用键盘验收，检查工作记录输入时保存按钮与系统键盘的真实坐标；构建结果见[发布记录](../app-store/README.md)。浏览器可见窗口模拟与原生模拟器不替代签名真机操作手感。


本轮 WebKit 390×844px 的实际渲染对照使用虚构工作区与 47/34px CSS 安全区模拟，包含预览说明，不作为原生截图或商店素材：[浅色四页](current/core-flow-1.8.8/overview-light.png) · [深色四页](current/core-flow-1.8.8/overview-dark.png)。单页：[今天](current/core-flow-1.8.8/light-today.png) · [案件](current/core-flow-1.8.8/light-cases.png) · [时间轴](current/core-flow-1.8.8/dark-timeline.png) · [对象详情](current/core-flow-1.8.8/light-object.png)。

## 连续编辑与对象关联（1.8.9）

- 标签、状态和明确确认的名称使用[公共保存队列](../../src/domain/caseHeaderQueue.ts)，每次修改在上一份实际回执上合并；快速连续修改按顺序写入，失败不成为下一次写入的基线。未确认的名称不随属性修改保存，失败时仅回退没有被更新编辑取代的字段。案件关闭等待提交完成，云端应用仍遵循原有公共编辑保护。
- [对象框架](../../src/case-system/registry.ts)以一次投影提供当前关注、对象及时间轴；旧归档关系查重改为索引，详情只在工作区变化时重新投影。继续使用同一业务状态和服务，页面不直接调用平台 SDK，不增加另一份同步数据或长期业务缓存。
- 关联先选择查找范围，再选择对象类型；当前案件提供本案对象，全部联系对象库提供可复用的人物、法官、法院与机构。材料等对象继续按案件归属选择；后台重新检查所有权。检索支持联系对象的名称、电话和地址，列表分批显示，选择起点使用单选、关联目标支持多选。
- 已有对象与新建入口在同一区域。新建界面取消后恢复原有检索、选择与说明；创建成功只补充选择，关系在点击“保存关联”后生效。独立对象一经保存会保留，关联表单说明这一点。关联属性复用同一选择器。
- 工作记录、关键节点、文档、待办及费用先展示主要内容，公共属性放在后方，折叠时只占一行。折叠指示器使用公共单色 CSS 形状，避免系统字体将默认三角渲染成彩色符号；触控区域仍至少 44px。案件卡片不显示空流程占位，保留实际节点、标签和待办。

新增回归覆盖慢速连续写入、失败后继续保存、未确认名称保留、目录范围、取消原位新建、插件一次投影，以及组件标识和尺寸观察循环。[交互对照](current/interaction-1.8.9/overview.png)来自 WebKit 实际浏览器渲染，使用虚构工作区、390×844px 和 47/34px CSS 安全区模拟；深浅主题通过应用设置切换，不作为原生或商店截图。单页：[浅色关联](current/interaction-1.8.9/light-association.png) · [深色关联](current/interaction-1.8.9/dark-association.png) · [浅色记录](current/interaction-1.8.9/light-record.png) · [深色记录](current/interaction-1.8.9/dark-record.png)。
