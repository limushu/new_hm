# 字体映射规范

## 字体族

应用 UI 统一使用 styles.css 中 --font-ui：Segoe UI、Microsoft YaHei UI、PingFang SC、Microsoft YaHei、system-ui、sans-serif，按平台可用字体依次回退。Windows 拉丁字符通常使用 Segoe UI，中文使用 Microsoft YaHei UI；macOS 中文使用 PingFang SC。统一原则是同一平台下相同内容角色一致，而非强制所有平台加载同一个外部字体。

按钮、输入框、下拉框、弹层、日期选择器、SVG 图内文字继承同一字体族，不让原生控件落回另一套字体。font-synthesis: none 避免浏览器制造伪粗体。无需联网下载字体，保持离线可用。

## 语义尺寸

所有应用 CSS 引用全局变量，不在组件中另写任意字号。根变量定义是像素值的唯一来源。

| 变量 | 大小 | 用途 |
| --- | --- | --- |
| --text-xs | 11px | 辅助标记、标签数量、图注 |
| --text-sm | 12px | 次要说明、字段名、紧凑菜单与日程元信息 |
| --text-base | 13px | 默认界面、列表、按钮、属性值 |
| --text-body | 14px | 阅读正文、主要卡片、分区标题 |
| --text-heading | 16px | 对话框及信息组标题 |
| --text-title-sm | 18px | 当前程序摘要、统计数字 |
| --text-title | 22px | 局部页面标题 |
| --text-display-mobile | 24px | 窄屏主标题 |
| --text-display | 28px | 案件名称及宽屏主标题 |

数字不随重要性无限放大。小字最小 11px；文本可读性主要靠对比、留白和层级，不靠增加所有控件高度。

## 字重、行距与图标

正文使用 400，强调、选中项使用 500，标题使用 600。避免 550 等缺乏跨平台一致性的中间字重。正文默认行高 1.5；标题和紧凑按钮可按现有组件使用更紧的行高，禁止用固定高度裁掉中文基线。

使用 --weight-regular / --weight-medium / --weight-strong 明确 400 / 500 / 600 的映射。案件功能分区标题统一为 --text-heading（16px）、600；正文及属性值保持 13–14px，不跟随标题整体放大。常规图标统一 --icon-stroke（1.7）和 --icon-muted，属性图标为 13px；案件页书页标识使用独立的柔和双色，HM 品牌独立于正文图标。

1.1.4 明确文字颜色按内容角色映射，不按字号或所在行是否次要来变灰：

| 内容角色 | 颜色变量 | 规则 |
| --- | --- | --- |
| 标题、正文、待办内容、备注、已填写属性值、实际日期及记录 | --text / --text-strong（同为 #ececea） | 标题靠字号和字重建立层级，正文保持同等清晰；输入、Select 和弹层不继承字段名的灰色 |
| 属性名、辅助说明、帮助入口、图标 | --muted / --icon-muted | 辅助识别，不覆盖对应属性值 |
| 占位、未填写、无内容提示 | --quiet | 输入框 placeholder、未指定的阶段和前序程序明确区别于真实内容 |
| 已完成、跳过、禁用、状态与危险操作 | 对应状态色或禁用规则 | 状态色保留语义，不把所有颜色统一刷白 |

案件页面默认只保留简短空态，不重复讲解“点击节点”“关联后显示”等操作；复杂阶段规则通过折叠帮助查看。删除影响、未保存错误、历史对象映射等会影响决定的信息仍按需呈现。

参考 Notion 的信息层级，不照搬参考图的截图缩放比例：宽侧页以书页标识、标题和紧凑属性建立开头，600px 以内收成行内标识与标题；概览功能保持逐行排列，主要用间距组织，保留关键分隔线而非每一段都画框。

金额、时间、日期和统计数使用 font-variant-numeric: tabular-nums，以便对齐。图表中的金额与账目共用金额格式化，不在图中省略影响理解的单位。默认界面图标使用同一 Lucide 线性图标族，常规 16px，辅助 12–14px；品牌标志使用独立 SVG，不把 emoji 混作功能图标。

## 检查方式

检查案件标题、案号输入、Select 弹层、DateField、侧栏、联系对象及 SVG 图表的 computed font-family；Windows 原生 WebView2 再用 CDP 检查中文实际渲染字体。确认日期和数字没有使用另一套系统原生控件字体。

不改写用户材料本身的排版：PDF、图片、导入文档的预览保持原文件字体与内容。历史 HTML 设计原型不是应用 CSS 的规范来源。

## 1.3 主导航与双主题

案件的概览、材料、流程详情、收支为一级页签，位于案件属性之后、办理路径之前，滚动时保持可见。四项共用 text-body、weight-medium、同一行高，选中项仅改变底色、图标和文字颜色，不改变字号或字重。窄侧页四项一同使用 text-base，不单独缩小某项；方向键、Home、End 可切换。

普通正文、日期与已填写字段统一使用 text；辅助标签使用 muted，空值使用 quiet。主题切换不改变字体族、字号或布局。页面分区用小面积蓝、青、紫、琥珀色图标区分，标题仍为中性正文色。新增图标沿用 Lucide，不混用 emoji。

颜色角色集中在 themes.css：背景层级、正文、辅助文字、边框、强调色、语义色及对应弱底色，深浅两套分别配置。不得通过反相滤镜实现浅色，也不为各页单独保留深色硬编码。PDF 等材料原本的白纸和文档内容保持原样。Windows 主题同步到窗口；主题偏好写入工作区设置，启动缓存只保存外观选择。
