# 外观选择与全屏布局

2026-11-17 用户确认：案件底部操作栏始终贴底，强调色可自选，并修正 iPhone 上下空白区域。1.8.3 为本轮实现候选，签名包状态见[内测记录](../app-store/README.md)。

## 布局

案件侧页保持统一滚动容器，以纵向弹性布局让正文撑满剩余高度；底部“录音 / 创建 / 查找”不随短内容上浮，长内容通过底部吸附保持可见，正文末尾仍可滚动到操作栏上方。四个主标签复用同一结构。

HTML 声明 `viewport-fit=cover`，公共 CSS 使用实际 `safe-area-inset-*`：背景覆盖视口，状态栏与手势区仅为控件保留必要空间。顶部有固定背景遮挡，避免滚动文字穿过状态栏；底部导航与案件操作栏为手势区留空间。触摸设备旋转到较矮横屏时，沿用手机导航和全宽案件页。

iOS [Host 驱动](../../crates/tauri-plugin-hm-host/ios/Sources/HostPlugin.swift) 在 WebView 加载时关闭系统额外内容避让，由同一套 CSS 统一处理安全区，防止重复缩进。深浅主题通过已有 [HostDriver](../../crates/hm-runtime/src/platform/ports.rs) 同步原生窗口、WebView 和滚动背景，系统模式使用动态系统外观。不移除状态栏或手势区，也不修改屏幕缩放。

## 自定义强调色

“设置 → 外观 → 强调色”提供六种预设、自选颜色及恢复默认。自选支持系统颜色选择器与 #RRGGBB 输入，明确应用后生效，取消保留原色。

[公共色彩用例](../../src/domain/accent.ts) 将用户颜色作为色种，为深浅主题生成按钮、强调文字、柔和背景和边框；调整明度使主按钮及强调文字达到至少 4.5:1 的对比度，悬停仍有可见变化。全局别名继续兼容各业务页面；案件状态、费用分类等业务语义颜色独立保留。

`accent_color` 经核心设置白名单和格式校验保存到 SQLite。浏览器缓存仅用于启动外观，正式应用以本机设置为准；新备份 ZIP 恢复保留目标设备的颜色，业务云同步不携带设备外观偏好。

## 验证

界面回归核对四个案件标签、长短内容、320/390/430px、横屏及桌面，检查操作栏位置与末条内容可读性。模拟安全区用于 CSS 布局检查，原生测试另使用真实 WKWebView/窗口核对视口高度与安全区值，以及深浅主题原生背景；模拟 CSS 不替代原生窗口测量。颜色单元测试覆盖预设与黑白、亮黄、纯色等极端输入，核心测试覆盖持久化、无效输入与备份保留。

最终签名 iPhone 仍需核对实际状态栏、底部手势、旋转、键盘出现/收起和字体缩放；浏览器及模拟器验证不代替真机手感验收。
