# 案笺 1.0.2 使用与验收

这是 Windows x64 安装版，供个人律师本地管理案件。无需账号，断网可使用；仅检查和下载安装更新需要网络。macOS、Android、iOS 仍需各平台构建和实机验收。

## 安装与数据

运行 `hm-workspace_1.0.2_windows-x64-setup.exe`，按提示安装到当前 Windows 用户。无需安装 Node 或 Rust。运行需要 Microsoft Edge WebView2；安装程序会在缺少时引导安装，因此首次安装可能需要联网。

数据通常位于 `%LOCALAPPDATA%\com.limushu.hm\`，准确位置见“设置 → 本地数据”。日常升级保留该目录。对外安装包不含开发测试案件或个人资料。软件尚无 Windows 商业代码签名证书，系统可能显示未知发布者；在线升级签名用于验证升级包来源，与 Windows 发布者证书是两回事。

旧安装版可覆盖安装，旧数据库在升级前自动保存到数据目录的 `migration-backups/`，再迁移到版本 4。升级后不要用旧程序打开新版数据库。历史绿色模式仍可识别；绿色版与安装版的数据目录彼此独立，不自动合并。若需搬迁，先用新版程序在原绿色目录创建完整备份，再在安装版设置中恢复，勿只复制运行中的数据库。

## 建议验收顺序

1. 打开案件页，选择“添加虚构示例案件”或自己新建案件。示例全部虚构，可删除。新建只需名称。
2. 将案件拖到其他状态列，退出再打开，检查位置保留。列标题菜单可改名和配色，最右侧可新增状态。
3. 进入案件，新增二审或执行程序；切换回一审检查原案号、阶段仍在。管理阶段可改名、排序、跳过；结束程序不会自动结案。记录事件可自行选择是否加入日历。
4. 材料页添加文件或从资源管理器拖入，重复导入同名文件，检查自动编号且原件不变。建立文件夹、移动、改名、导出副本；双击 PDF、图片、录音预览。Word、Excel 由默认软件打开归档副本，保存即修改该副本。
5. 点击录音并允许麦克风，依次开始、暂停、继续、结束、保存，检查播放、改名和备注。无权限或无设备时应显示错误。
6. 新增或关联联系人，指定本案身份；法院、法官选择具体程序。点击对象名称先看资料，再切换反向关联或局部关系图。删除有关联的对象，核对其他对象和案件未删除、程序历史名称仍保留。
7. 在收支页填写约定律师费，记录律师费收入和支出；可选程序、凭证及报销状态，检查汇总。金额按分保存。退款和部分报销未纳入复杂核算规则。
8. 新建工作记录并修改，添加附件；移入回收站后恢复。案件侧页右上角可删除，也可在看板拖入回收区并撤销。案件和材料同样先入回收站，彻底删除必须再次确认。
9. 添加待办时点击日期整块选择，也可直接输入日期；不填日期仍可保存。日程、待办、程序事件和收支使用同一日期组件。所有普通下拉框支持方向键、回车和 Escape。
10. 在日历的半小时空白格新建安排，检查默认半小时、个人日程不预选案件；试用日、周、月视图及重叠日程。设置提前提醒后，可从左上角通知入口查看；后台系统提醒需应用仍运行且 Windows 允许通知。
11. 用左上角搜索或 `Ctrl+K` 搜索案件、对象、材料文件名；材料结果应进入所在案件和文件夹。不检索文件正文。
11. 设置备份位置并立即备份，另建一项测试内容，然后选择刚才的 `hm-backup-…` 文件夹恢复。确认后替换当前工作区，恢复前副本保存在数据目录的 `recovery/`。
12. 在设置检查更新；没有新版时显示当前已是最新，有新版时由你确认下载和安装。下载失败不替换程序；升级前必须成功备份。

## 备份与提醒边界

每天应用运行时自动备份一次，默认保留最近 7 份；默认位于同一数据目录，建议另选磁盘以防整盘损坏。备份是包含清单、数据库和材料的整个文件夹，请完整保留；恢复会验证文件哈希、数据库和材料是否齐全。恢复过程中断时，下次启动依据恢复日志退回恢复前副本。旧材料文件代际可能暂留，以免影响被外部软件占用的文件；完整备份只包含当前归档引用。

关闭主窗口默认驻留托盘；从托盘退出后停止提醒。开机启动是可选项。电脑休眠或应用未运行期间不能即时通知，恢复运行后补提醒最近 24 小时内到期且尚未送达的日程。全天日程按本地上午 9 点计算提醒；日期与时间使用本机墙上时间，不做跨时区转换。关键法律期限由用户核对填写，不自动推算。

## 验证范围

已使用隔离的虚构数据验证业务核心、界面流程和 Windows 原生文件/PDF/录音/数据库备份恢复与重启。录音自动化使用模拟设备，仍需你用实际麦克风试听。其他电脑的安装、不同音频设备、Office 保存、系统通知及开机启动需要实机确认；不把单机自动化等同于所有设备验收。

当前不含云同步、多人协作、AI、全文搜索、录音转写、重复日程或自动法律期限计算。Notion 配色、圆角、字体与图标持续打磨标记保留。

## 1.0.2 新增验收

- 案件侧页打开后点击左侧主页面：有效名称保存并返回；空白草稿取消；在侧页内操作不误关闭。
- 案件信息中搜索办理法院和承办法官。已有对象可直接选，缺少时明确选择新建；选择后即可在联系对象详情看到本案件，不再手动重复关联。
- 在不同程序选择不同法院/法官，再切回原程序检查原关系保留。改变法院会清除当前程序原法官，需要重新确认。
- 点击法院或法官属性旁的箭头，查看反向案件和关联对象；可切换局部关系图、点击节点、调整层级/缩放、拖动空白处。
- 编辑法官可调整关联法院；此设置用于候选筛选，不改写历史程序已有的法院。旧数据重名歧义会保留原文字，等待明确选择。
