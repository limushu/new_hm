# 案笺 1.4.2 使用与验收

这是 Windows x64 安装版，供个人律师本地管理案件。无需账号，断网可使用；仅检查和下载安装更新需要网络。macOS、Android、iOS 仍需各平台构建和实机验收。

## 安装与数据

运行 `hm-workspace_1.4.2_windows-x64-setup.exe`，按提示安装到当前 Windows 用户。无需安装 Node 或 Rust。运行需要 Microsoft Edge WebView2；安装程序会在缺少时引导安装，因此首次安装可能需要联网。

数据通常位于 `%LOCALAPPDATA%\com.limushu.hm\`，准确位置见“设置 → 本地数据”。日常升级保留该目录。对外安装包不含开发测试案件或个人资料。软件尚无 Windows 商业代码签名证书，系统可能显示未知发布者；在线升级签名用于验证升级包来源，与 Windows 发布者证书是两回事。

旧安装版可覆盖安装，旧数据库在升级前自动保存到数据目录的 `migration-backups/`，再迁移到版本 7。升级后不要用旧程序打开新版数据库。历史绿色模式仍可识别；绿色版与安装版的数据目录彼此独立，不自动合并。若需搬迁，先用新版程序在原绿色目录创建完整备份，再在安装版设置中恢复，勿只复制运行中的数据库。

## 1.4 工作主线验收

1. 建案后不自动生成一审。可直接记待办，也可在“办理”明确新增一审和独立专项；非诉流程不要求法院或原告身份。
2. 在一审选中“举证”，确认只改变浏览，阶段状态不变。在其中添加带日期的待办、等待对象和完成结果；概况和日历是同一任务，在日历改日期后回本阶段核对。
3. 在阶段上传材料并标注用途；另一个流程通过“关联已有材料”复用，材料库中仍只有一份原件。从阶段进入材料库显示明确范围，可清除或返回办理。
4. 阶段中记支出并直接选凭据，费用页看到同一笔金额；从费用页普通入口看全案，阶段入口看明确范围，列表/图/合计一致。
5. 设置收费节点、金额和日期或条件；核销已有实际律师费收款，核对不会新增账目，也不能超过节点或实收。条件未确认保持未到期，完成阶段不自动生成收款。
6. 明确完成、重开或删除阶段，核对任务、材料、日程、费用及历史保留；删除后工作归属仍在原流程。使用清单明确添加，重试不重复。
7. 多个流程时在办理页展开“流程关系”；其他三个页面不出现路径图。流程资料与当事人、事项与变更按需展开。保持现有双主题及可读字号。

下方旧版本分节是历史验收记录，页面职责和阶段操作以本节为准。完整规则见[工作空间规格](https://github.com/limushu/new_hm/blob/v1.4.2/docs/design/case-workspace.md)。

## 常规验收顺序

1. 打开案件页，选择“添加虚构示例案件”或自己新建案件。示例全部虚构，可删除。新建只需名称。
2. 将案件拖到其他状态列，退出再打开，检查位置保留。列标题菜单可改名和配色，最右侧可新增状态。
3. 进入案件，明确新增一审流程，再新增二审或执行；切换回一审检查原案号、阶段仍在。管理阶段可改名、排序、跳过；结束程序不会自动结案。记录事件可自行选择是否加入日历。
4. 材料页添加文件或从资源管理器拖入，重复导入同名文件，检查自动编号且原件不变。建立文件夹、移动、改名、导出副本；双击 PDF、图片、录音预览。Word、Excel 由默认软件打开归档副本，保存即修改该副本。
5. 点击录音并允许麦克风，依次开始、暂停、继续、结束、保存，检查播放、改名和备注。无权限或无设备时应显示错误。
6. 新增或关联联系人，指定本案身份；法院、法官选择具体程序。点击对象名称先看资料，再切换反向关联或局部关系图。删除有关联的对象，核对其他对象和案件未删除、程序历史名称仍保留。
7. 在费用页填写约定律师费，记录律师费收入和支出；可选程序、凭证及报销状态，检查汇总。金额按分保存。退款和部分报销未纳入复杂核算规则。
8. 新建工作记录并修改，添加附件；移入回收站后恢复。案件侧页右上角可删除，也可使用看板卡片右上角删除按钮并撤销。案件和材料同样先入回收站，彻底删除必须再次确认。
9. 添加待办时点击日期整块选择，也可直接输入日期；不填日期仍可保存。日程、待办、程序事件和收支使用同一日期组件。所有普通下拉框支持方向键、回车和 Escape。
10. 在日历的半小时空白格新建安排，检查默认半小时、个人日程不预选案件；试用日、周、月视图及重叠日程。设置提前提醒后，可从左上角通知入口查看；后台系统提醒需应用仍运行且 Windows 允许通知。
11. 用左上角搜索或 `Ctrl+K` 搜索案件、对象、材料文件名；材料结果应进入所在案件和文件夹。不检索文件正文。
12. 设置备份位置并立即备份，另建一项测试内容，然后选择刚才的 `hm-backup-…` 文件夹恢复。确认后替换当前工作区，恢复前副本保存在数据目录的 `recovery/`。
13. 应用启动后及每 6 小时检查更新，新版在侧栏提示，也可在设置检查；没有新版时显示当前已是最新，有新版时由你确认下载和安装。下载失败不替换程序；升级前必须成功备份。

## 备份与提醒边界

每天应用运行时自动备份一次，默认保留最近 7 份；默认位于同一数据目录，建议另选磁盘以防整盘损坏。备份是包含清单、数据库和材料的整个文件夹，请完整保留；恢复会验证文件哈希、数据库和材料是否齐全。恢复过程中断时，下次启动依据恢复日志退回恢复前副本。旧材料文件代际可能暂留，以免影响被外部软件占用的文件；完整备份只包含当前归档引用。

关闭主窗口默认驻留托盘；从托盘退出后停止提醒。开机启动是可选项。电脑休眠或应用未运行期间不能即时通知，恢复运行后补提醒最近 24 小时内到期且尚未送达的日程。全天日程按本地上午 9 点计算提醒；日期与时间使用本机墙上时间，不做跨时区转换。关键法律期限由用户核对填写，不自动推算。

## 验证范围

已使用隔离的虚构数据验证业务核心、界面流程和 Windows 原生文件/PDF/录音/数据库备份恢复与重启。录音自动化使用模拟设备，仍需你用实际麦克风试听。其他电脑的安装、不同音频设备、Office 保存、系统通知及开机启动需要实机确认；不把单机自动化等同于所有设备验收。

当前不含云同步、多人协作、AI、全文搜索、录音转写、重复日程或自动法律期限计算。Notion 配色、圆角、字体与图标持续打磨标记保留。

## 1.3.2 页面比例与密度验收

- 检查案件标题、正文、操作与辅助信息各有层级，页头图标/名称同行，状态/标签紧凑排列。
- 材料页不重复显示“材料”标题或根目录路径；进入文件夹后显示逐级路径，上传/录音/拖入仍归档到当前位置。
- 文件名为 15px，操作为 14px，日期和大小为 13px；不同侧页宽度保持字号一致，不能依靠整体缩小实现适配。
- 在 800×600 窗口、未滚动时完整看到至少四行普通短名称材料，宽屏使用单行工具栏，极窄侧页搜索独立一行，日期列按空间隐藏。

## 1.3.1 历史字体与材料导航验收（字号和页头以 1.3.2 为准）

- 检查材料文件名、搜索、操作、流程范围与路径为 16px，表头、日期、大小为 14px；实际文件信息与标题同色，深浅模式保持一致。
- 材料页仅有一套归档范围导航，不显示重复的办理路径与归档教程；在一审下建立“证据 / 书证”，添加文件应进入书证，逐级路径可直接返回。
- 切换案件共用与一审，核对两边材料隔离；从概览材料入口和全局搜索进入仍应定位正确范围及文件夹。
- 在 1600/1024/800/390px 宽度检查材料工具栏和路径，正文不缩小，窄侧页隐藏日期列，按钮换行且没有页面横向溢出。移动端仅为布局验证。

## 1.3.0 主题、导航与凭据验收

- 设置 → 外观选择浅色、深色或跟随系统。切换后检查案件、日历、联系人、弹层与收支，关闭并重新打开后保留选择；跟随系统时系统外观变化同步生效。
- 四个主标签同字号、同字重；选中有弱蓝色底，滚动案件页时仍可切换，方向键/Home/End 可操作。窄屏不挤出窗口。
- 两个流程查看其中之一、关注另一流程，核对“查看中”与“当前关注”文字分别对应正确节点；承接箭头从前序指向后序，独立流程不被错误连线。
- 在收支“记一笔”选择文件并填写金额、报销状态后保存，凭据自动出现在材料中，无需先去材料页。取消窗口不产生材料。保存失败不留半笔账目或新文件，重复提交同一上传不重复导入。
- 编辑收支可更换凭据或选择已有材料；取消仅放弃本次修改，旧凭据和原始文件保留。当前每笔关联一份文件，多页票据可使用 PDF。

## 1.2.0 流程与我方身份验收

- 新建案件只保存档案，不生成一审，也不再显示无效的创建一审勾选项。明确点击“新增流程”后选择诉讼/非诉模板、名称及前序。
- 新建“专项尽调”模板，定义阶段后建立流程；编辑模板再建立另一个流程，核对旧流程名称和阶段未改变。删除模板后旧流程仍可查看。
- 在“委托与当事人”选择“我方委托人”，填写姓名与服务；一审记录原告，二审记录被上诉人，执行记录申请执行人。新流程应先显示身份未填写，不能自动复制一审身份。
- 查看一审但关注二审时，概览仍显示二审的身份。明确设一审为关注后，概览才显示原告。各功能保持单列布局。
- 可以直接录入姓名而不建联系对象；关联已有对象后，从对象详情和关系图可反查案件与各流程身份。删除对象或解除关联，案件中的姓名、身份保留；移除当事人须确认，不删除对象。
- 卡片右上角点击垃圾桶，确认后入回收站，可撤销或在回收站恢复。拖拽只改变看板状态，不再提供不稳定的拖拽删除目标。
- 390px 界面宽度及 800×600 桌面窗口检查身份编辑、联想菜单和流程模板弹窗，不应横向溢出。手机仅为布局回归，未发布移动端包。

1.2.0 已通过 40 项核心、1 项 Windows 路径、17 项前端逻辑、59 项界面测试及正式构建的隔离 Windows 原生回归。新增身份在备份恢复和重启后保持，中文实际渲染为 Microsoft YaHei UI。

## 1.2.0 任务栏图标缓存修复

- 启动时定向刷新本安装 exe 与 branding/hm-mark.ico 的 Shell 图像缓存项，避免窗口已换图标、任务栏分组仍沿用旧图。
- 不更改稳定应用标识，不删除系统图标缓存，不重启 Explorer 或强制关闭用户程序。
- 原生验收需同时核对 exe、窗口大小图标、Shell 缓存与实际任务栏；不能以应用侧栏图片代替任务栏验收。

## 1.1.4 花体 HM 与阶段删除验收

- HM 改为连笔花体，H 与 M 共用中间笔画；应用侧栏、exe 资源、窗口大小图标与安装快捷方式使用同一矢量源。
- 程序详情点击当前阶段，可选择“删除此阶段”；“管理阶段”中各阶段也有删除按钮。删除前确认，取消不改变数据。
- 删除当前阶段后显示“尚未指定阶段”，不自动切换其他阶段；已完成、待办理和已跳过阶段也可删除。既有程序事件、阶段历史和材料保留，删除动作另记入历史。
- 可删除至没有阶段，再添加自定义阶段。程序已办结时保留原只读规则，恢复办理后可调整。

## 1.1.3 后台更新提示与标签联想验收

- 新版默认在启动 15 秒后、运行期间每 6 小时检查；有更高版本时显示提示，无新版时不占位置。后台检查失败不影响离线使用，设置仍可手动检查及配置更新源。
- 点击新版提示应直接看到版本说明和“下载并安装”，当前日历或案件不跳转到设置。取消后继续工作，确认才开始备份、验签和安装；面板显示下载进度和失败信息。窄窗口也能打开此面板。
- 在案件类型输入 #名称，已有标签应联想提示；方向键和回车可选，模糊输入直接回车优先复用已有项。需要不同的新名称时明确点击“创建”。新标签保留为后续候选，移除当前案件标签不会删除候选。
- 案件状态同样支持 #输入、搜索及原位创建，但保持单选；新状态立即成为看板列，后续案件可复用。默认及已有状态也出现在联想中；不重复创建同名状态。已有旧库同名项不自动合并。
- 中文输入法组词期间回车不提交，Escape 关闭候选而不退出案件；长名称和窄窗口菜单仍应保持在窗口内。

## 1.1.2 程序详情与小屏验收

- 程序详情顶部默认使用紧凑程序导航，点一审、二审、执行直接切换资料；展开办理路径仍可查看承接连线，查看其他程序不会改变当前关注。
- 当前办理阶段优先展示；程序资料按案号、承接自、法院、法官逐行排列。程序事项、联系人和变更历史各自分区，阶段帮助默认收起。
- 将桌面窗口缩至 800×600，检查侧页内字段及按钮不横向溢出，阶段自动换行。宽屏中的窄侧页同样按侧页宽度适配；展开案件后可用宽度增加。
- 在窄窗口打开前序程序菜单、搜索法院、管理阶段，确认菜单留在窗口内且仍可选取。手机尺寸是浏览器布局回归，移动端安装包尚未发布。

## 1.1.1 单列、HM 与阶段重开验收

- 案件概览各功能纵向依次排列，一行一个分区，展开侧页和窄屏均保持同一阅读顺序。
- 图标改为 HM 组合，程序资源及窗口大小图标一致，安装快捷方式引用独立 branding/hm-mark.ico。请退出旧实例，安装后从新版入口启动；不会强行结束正在办理案件的旧程序。
- 在“程序详情”选择举证为当前，检查原阶段仍待办理，不被自动完成。在“管理阶段”点某阶段的“状态”，可标记完成、跳过或设为当前。
- 将中间阶段标记完成，再直接点击已完成阶段重新打开为待办理，检查后续已完成阶段和当前阶段保持原状。也可明确选择“当前办理”重新进入此阶段。
- 展开阶段变更记录，检查能看到完成与重开的前后状态，最新记录在前，旧完成记录保留；重复保存相同状态不新增记录。

## 1.1.0 案件全貌验收

- 同一委托或争议先建立一个案件档案。在顶部新增一审、二审、执行，明确选择“承接自”或独立程序，确认全部节点直接可见、原案号及阶段保留。旧库程序不自动连线。
- 点击历史节点只是查看；观察当前关注标记保持原位。点击“设为当前关注”才改变概览。允许多个程序办理中；办结当前程序后取消其关注，不自动把整个案件结案，也不替用户选择下一个程序。恢复办理不抢占其他关注。
- 每个程序内部调整阶段；阶段历史默认折叠，人工程序事项单独展示。已办结程序先恢复办理再调整阶段。前序不得选择其他案件或形成循环。
- 概览填写争议焦点与办理目标，查看当前关注的阶段、案号、法院/法官、相关人员、待办、日程及材料分布。点击相关人员先看资料。
- 在日历创建安排并主动关联案件，案件概览应显示同一条安排。在案件页修改标题或时间，回日历核对同步且未复制。案件内主动新增日程会预选当前案件，仍可取消。
- 在类型栏输入 #标签并回车，后续案件可搜索复用已有名称；移除此案标签不会删除候选。材料页选择案件共用或具体程序，导入前核对“归档到”位置；程序内可建阶段文件夹。
- 收支环图显示收入/支出分类与占比，点击分类筛选明细；图表始终统计全案。律师费进度只计律师费收入，报销单独核算，超出约定时明确显示超收。
- AJ 图标用于窗口、任务栏、托盘和快捷方式。升级后检查这些位置；已固定的失效旧快捷方式可能需要重新固定当前安装入口，不强行清理系统缓存。
