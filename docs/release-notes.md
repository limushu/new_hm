案笺 1.1.1 · 单列概览与可重开阶段

- 案件概览改为单列纵向阅读，每行一个功能分区；案情摘要、相关人员、待办、日程、材料与工作记录分别占满内容宽度，长摘要不再局部裁切。
- 标志按用户指定改为 H / M 几何组合；更新程序、窗口、任务栏、托盘与安装器图标。安装包携带独立 HM 图标文件，快捷方式明确引用，减少旧图标缓存影响。
- 阶段顺序仅作办理参考。切换当前阶段不会自动把原阶段标记完成，完成、跳过、重新打开由用户明确操作。
- 支持将中间任意已完成阶段重新打开为待办理，保留其他阶段的完成状态与当前阶段；也可明确重新设为当前。
- 阶段变更历史记录完成、重开和切换前后的状态，最新在前，重复保存不刷日志，重开不会抹掉历史。

数据库结构仍为版本 5。保留已有案件、程序、材料、升级公钥与数据目录。旧版阶段状态不擅自回填或重置，用户可以按实际情况重新打开。Windows 发布者证书尚未配置。
