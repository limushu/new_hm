案笺 1.4.0 · 案件工作空间

- 重整为“概况 / 材料 / 办理 / 费用”。概况看全案，办理处理实际工作；流程关系图仅在办理页按需展开。
- 阶段内直接管理待办、等待事项、处理结果、日程、材料、工作记录和相关费用；浏览阶段不修改状态。
- 任务与日历使用同一记录，可在日历直接调整截止日期；阶段提供可编辑、防重复的工作清单。
- 材料统一归档，可供多个流程和阶段引用并标注用途；材料库默认全案，阶段入口带明确、可清除的筛选。
- 新增收费节点，区分条件、到期待收和未到期；实际律师费收款可部分核销，防止重复计算。整案约定未填写与明确免费分别显示。
- 支出就地上传凭据，材料、金额与阶段关联一起保存；删除或重开阶段保留任务、材料、日程、账目及收费安排。
- 保持双主题与现有字号比例，简化单流程导航，资料和历史按需展开，完善小屏换行。

Windows x64 安装版，数据库升级至版本 7，旧库先保存检查点备份。旧记录不猜测阶段归属；原数据目录、材料 ID、备份和升级公钥保持兼容。
