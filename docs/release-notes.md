案笺 1.7.6（24.1）· 统一按钮与录音转文字

- 统一新建日程、新建案件、新建对象按钮的尺寸、图标、字体、圆角和主题色，名称完整。保存/取消、材料、录音和更新操作复用基础规格，窄屏表单按钮允许换行。
- iOS 结束录音后可点「转成文字」；已有音频在预览中也可发起。原录音先归档，文字可编辑后另存为同一案件中的文档，并关联原录音。
- 使用 Apple Speech 设备内识别，支持普通话、英语，取决于设备与本地语言资源。首次使用请求语音识别权限，不回退云端，不要求 AI 密钥。
- 识别按音频分段进行；停止、切后台或失败时保留已识别文字，可确认保存部分结果。关闭前提示处理未保存内容，失败重试不重复归档原录音。
- 联系对象页的「新建对象」与标题同行；「关系图」移到搜索和类型筛选区，手机搜索框独占一行。
- 更新应用内、公开隐私政策与审核备注；其他平台保留语音驱动接口，暂不显示转写入口。

沿用 schema 9，无数据库迁移。自动化覆盖驱动生命周期、真实 PCM 音频转换、原件保留、派生文档事务、授权失败、取消、超时与编辑保存；识别引擎在自动化中使用替身，实际识别质量需要 iPhone 真机验证。本次生成 TestFlight 候选，不自动替换 App Store 审核构建。真机录屏应与准备重提的构建一致。
