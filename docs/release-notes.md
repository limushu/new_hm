案笺 1.7.7（27.1）· 今天描边与统一对象详情

- 清单日期栏给今天添加主题色描边，与选中日期的填充色区分；清单顶部移除独立今天和前后切换，不新增日期选择入口。点击已有的今天导航返回当天；新建日程保持在顶部日期标题旁。
- 点击时间轴条目，直接在统一详情中查看内容、信息、自定义属性和关联对象。录音在详情内播放，关闭后回到时间轴，不再自动露出另一层详情。
- 文本、图片与 PDF 在页内预览；明确选择全屏预览才切换页面，返回按钮标明回到详情。材料页的独立音频预览也改为紧凑播放器。
- 省略号打开常用操作菜单：查看详情、编辑信息、标为重要；材料和记录可经确认移至回收站。移除旧的独立条目设置界面。
- 标签与重要程度在同一详情中编辑，明确保存或取消；内容编辑器和全屏预览替换主详情界面，关联导航复用当前详情并支持返回。
- 离开播放器或切换对象时停止播放，不自动播放录音。保留设备内转写入口与原录音。
