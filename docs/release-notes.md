律师工作台 1.0.1 · 对象关系与信息页优化

- 点击案件侧页外的主页面返回；有效名称先保存，空白草稿取消，保存失败留在当前页。
- 办理法院、承办法官改为可搜索的已有对象选择，支持按需原位新建；选中后直接建立程序关系。
- 法院与法官支持独立关联；候选法官按办理法院筛选，不再重复填写文字和手动再关联。
- 对象详情增加去重的反向案件列表、关联法院/法官及可点击的局部关系图，支持层级、缩放和移动。
- 统一系统字体回退、字重和行距，保留已认可的日历及看板配色布局。
- 数据库升级至 4，升级前保留副本；旧文字记录按无歧义匹配复用对象，不自动合并重名对象。可恢复 1.0.0 的完整备份。

安装版内可检查更新，下载验证签名并在安装前备份。Windows 发布者证书尚未配置。
