案笺 1.1.2 · 程序详情层次与小屏适配

- 程序详情以当前办理阶段为第一焦点，再依次展示程序资料、事项和案件联系人；用单列属性与细分隔线替代分散的双列表单。
- 顶部办理路径在详情页收为紧凑程序导航，按需展开承接连线图；移除重复的“查看程序”下拉框，查看与关注仍各自独立。
- 阶段操作说明默认收起，法院/法官仅在需要确认时显示提示，减少空内容与说明文字占用的空间。
- 以案件侧页自身宽度决定布局：窄侧页缩减边距、阶段换行、工具栏换行，长名称与菜单保持在可用宽度内。
- 保留阶段重新打开、程序并行、材料归属、案件日程同源及 HM 图标。

数据库结构保持版本 5，沿用原数据目录与升级签名公钥。Windows x64 安装版；移动端尚未发布。
