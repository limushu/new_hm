案笺 1.7.5 · 按类型添加人员与机构，复用已有档案

- 案件「创建 → 人物或机构」与「人员 → 添加人员或机构」共用流程：先确认个人、机构、法院或法官类型，再选择已有档案或新建。
- 已有对象按类型搜索本机全部档案，包括其他案件使用过的对象；添加到本案后复用同一档案，显示本案身份，重复添加同一身份不产生重复关系。
- 法院、法官可直接加入案件，不再要求先有办理流程；之后可关联一审等节点。明确设置办理流程的法院与法官仍保留原有历史和校验。
- 新建对象与案件身份在后端同一事务保存，失败时回滚；取消不建档。同名对象显示复用入口，不擅自合并。
- 名称与电话放在前面，地址、备注按需展开；本案身份与公共属性放在资料之后。按钮和选中状态沿用自适应主题强调色。

沿用 schema 9，不新增数据库迁移。本次先用于 TestFlight 验证，不自动替换 App Store 审核构建；真机录屏应使用准备重提的同一构建。
