案笺 1.1.4 · 花体 HM 与阶段删除

- HM 图标改为手写连笔花体，两个字母共用中间笔画；黑色底层、不规则深灰内层与青蓝紫渐变字形。应用侧栏、Windows exe、窗口大小图标和安装快捷方式同步使用。
- 程序详情点击当前阶段可直接选择“删除此阶段”；“管理阶段”中也可删除当前、待办理、已完成或已跳过阶段，删除前明确确认。
- 删除当前阶段后暂不指定当前阶段，由用户选择下一步；不自动推进程序，不改其他阶段状态。删除动作追加历史，既有事件、变更记录和程序材料保留。
- 正文与已填写属性采用和标题一致的文字颜色，灰色留给占位、未填写及辅助说明；删减案件页重复操作提示，保留必要的删除影响说明。
- 阶段可全部删除并重新添加，剩余顺序自动整理；程序已办结时沿用只读规则，恢复办理后可调整。

数据库结构保持版本 5，沿用原数据目录与升级签名公钥。Windows x64 安装版；移动端尚未发布。
