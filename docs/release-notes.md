案笺 1.6.0 · 统一案件对象与工作空间

- 主分区调整为脉络、材料、关系、费用；旧程序/阶段资料保留在案件管理的历史入口。
- 所有案件对象共享引用、标题、类型、重要程度、标签、业务时间和关联关系；人物、机构、材料和文件夹也可设置属性。
- 创建时可设置重要程度、标签、关联节点，并直接导入本地存量材料。
- 一审、二审等可创建为自由命名的关键节点，日期可留空；节点详情能够打开关联材料和事项。
- 材料列表与费用页面采用统一配色和按钮；实际账目优先，收费约定及分类分析按需展开。
- 公共属性批量保存，属性失败后的重试复用已保存正文；保留既有原件、账目、归档及核销规则。

沿用 schema 8，不新增数据库迁移。模板、Word 编辑器、甘特图继续保留接口，尚未启用。App Store 原提交保持不变。
