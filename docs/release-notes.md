案笺 1.7.1 · 统一编辑与关联交互

- 深浅主题的主操作按钮统一配色，日程入口沿用同一组主色。
- 案件卡片按内容自适应高度，保留完整信息；状态筛选改为单行，窄屏可横向查看。
- 属性名称、类型、内容在同一页填写并保存，关联属性可在同一次保存中选定对象。
- 弹窗关闭图标保持简洁，触摸打开时不再自动聚焦关闭按钮，键盘焦点提示保留。
- 案件名称和流程编号改为显式保存；取消放弃草稿，离开未保存的案件名称时可选择保存或放弃。
- 关联先选对象类型，再选择已有对象或新建；当前案件范围清楚显示，批量关联在确认时统一提交。

沿用 schema 9，不新增数据库迁移。跨案件的材料/节点关联未开放，联系人库中的人物与机构可复用。原件、对象身份、账目和核销规则保持。本次用于 TestFlight，不替换原 App Store 提交。
