案笺 1.1.0 · 案件全貌与并行办理

- 同一委托或争议使用一个案件档案，内部容纳一审、二审、再审、执行等多个程序。顶部节点直接展示全部程序、办理状态、案号及明确的承接连线。
- 支持多个程序并行办理，“查看程序”不改变“当前关注”；程序可标记办结、恢复办理，不自动关闭整个案件。历史数据不推测前序程序。
- 概览汇总案情摘要、当前关注与阶段、相关人员、待办、案件日程及材料分布。程序内阶段与自动变更历史分开展示，日志默认折叠。
- 日历关联案件后自动出现在案件概览，可直接编辑同一日程；材料的共用/程序范围及导入目标清楚可见。
- 案件类型支持持久化 #标签，并可在后续案件复用；收支新增分类环图与律师费收款进度。
- 字体、字号与字重按统一语义变量映射，并写入设计文档。更新 AJ 品牌标志及 Windows 可执行文件、窗口与快捷方式图标配置。
- Rust 后台检查新版本，侧栏主动提示，用户确认后才下载、验签、备份并安装。支持优先 HTTPS 更新源及 GitHub 回退，提供 GitLab/自有下载站镜像包准备脚本；国内镜像服务尚需提供实际地址部署。

旧库升级前自动备份，迁移至数据库版本 5。保留原应用标识、个人数据目录及升级公钥。Windows 发布者证书尚未配置；macOS、移动端及跨电脑安装仍需单独验收。
