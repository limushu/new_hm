案笺 1.7.3 · 标签布局与编辑后的响应

- 手机案件详情的状态和标签分行对齐，缩短添加标签入口；长标签可换行。
- 各页签保留一致的顶部区域，切换脉络、材料、人员和费用时不再隐藏标签栏、移动页签位置；触摸屏不再保留鼠标悬停底色。
- Rust 保存案件名称、标签或状态后直接返回规范化的案件头部信息，前端只合并这些结果，不再重新读取整份工作区；创建状态也只更新状态列表。
- 保留无关材料、账目等集合的引用，工作与案件资料首次展开时才加载；后台视图保留输入状态。
- 标签或状态保存失败时还原显示，错误提示后可重试；触摸添加标签后退出输入焦点。

沿用 schema 9，不新增数据库迁移。本次用于 TestFlight，不替换原 App Store 提交。
