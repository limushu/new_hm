案笺 1.5.0 · 案件系统第一阶段

- 时间轴统一显示进展、工作记录、文书、材料、录音、收支、待办及日程，保留各自日期含义。
- 事项可以标为重要、设置标签，组合筛选类型、重要程度和标签。
- 事项可关联本案材料、人物、部门及其他资源；关联附件直接进入原件预览。
- 人物与机构之间可建立本案关系，显示在关系图中。
- 从时间轴编辑收支使用原账目，费用视图同步更新，保持既有核销和凭据规则。
- 新增受信模块注册及详情编辑器适配接口，预留文书编辑、模板、计划服务。进阶编辑器、模板引擎和甘特图尚未实现。

数据升级至 schema 8。升级前自动保留旧数据库副本，沿用材料归档目录、资源 ID 和备份机制。旧版应用无法直接打开已升级数据库。

建议测试：已有案件历史与材料 → 创建事项与收支 → 设置重要程度/标签 → 组合筛选 → 添加材料/人物关联 → 编辑费用并核对账目 → 重启后检查保存结果。

本次通过 TestFlight 提供测试，不替换原有 App Store 提交。
