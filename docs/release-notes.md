案笺 1.0.2 · 资料优先与交互统一

- 原“律师工作台”更名为“案笺”，加入折页案卷图标；保留应用标识、原数据目录、升级公钥及旧安装身份。
- 全应用普通下拉菜单统一为中性深灰面板、圆角、选中标记和键盘操作；已有对象的搜索菜单同步统一，弹层不被对话框裁切。
- 联系对象默认进入详情，关联案件和关系图独立查看；有案件、法院或法官关系的对象也可删除，确认后自动解除关联，保留其他对象、案件及程序历史文字。
- 案件详情右上角明确提供删除案件；看板可拖到回收区删除，支持撤销、键盘操作及回收站恢复。
- 添加待办改为与日程编辑相近的小型弹窗，日期可留空。待办、日程、程序事件、收支共用日期选择器：整块点击选择、直接输入、今天与清除日期，非法日期不能提交。
- 统一界面与弹层字体回退及 400/500/600 字重，保留已确认的日历布局和配色。

安装版内可检查更新，验证签名并在安装前备份。Windows 发布者证书尚未配置。
