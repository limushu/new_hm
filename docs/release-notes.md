案笺 1.7.0 · 简明案件工作空间

- 案件卡片按状态采用低饱和色面与细色条，保留进度、标签及近期待办信息。
- 首页集中展示当前关注节点、下一件事及案件时间轴。
- 人员页直接展示当事人、律师、法官、法院和机构；创建入口支持新增人物、机构及日程。
- 对象可添加自定义文本、数字、日期、选择、复选框与关联属性；可选择存量对象或新建并关联。
- 费用保留可点击的分类饼图；手机今日默认清单，仍可切换时间表。

数据库升级至 schema 9，升级前保存数据库副本。旧版应用无法直接打开升级后的数据库。原件、资源 ID、账目及既有核销规则保持；模板与进阶编辑器尚未启用。本次用于 TestFlight 测试，不替换原 App Store 提交。
