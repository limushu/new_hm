案笺 1.4.4 · 案件脉络与随手记录

- 案件概况先显示当前流程、阶段和下一项到期待办，再以时间轴呈现关键事件、工作记录与归档材料。
- 发生日期、记录时间和归档时间分别标注；未来的关键事件收在“后续计划”。未填写的日期不会推测补齐。
- 录音、创建与全案材料查找固定在快捷操作栏。可直接创建关键事件、工作记录、待办和本地文本文件。
- 新建 Markdown / 文本文档由原生文件归档保存，可在应用内阅读、查找并通过材料页导出；同名文件保留各自内容。
- “相关人”集中呈现当事人、法院、法官及其流程身份，并提供本案关系图与资料维护入口。
- 手机端将完整工作资料折叠，首屏保留进度与脉络。采用暖白、石墨与少量灰绿色，增加留白，同时保留深色模式。

数据库仍为版本 7，沿用现有数据目录、备份和材料归档。新版先通过 TestFlight 验证，不替换正在审核的 1.4.3 App Store 提交。

验证时建议：打开已有案件，查看历史材料及工作记录；新增过去事件与未来计划；创建文档并重新打开；打开相关人与关系图；从快捷栏启动、结束并保存一段录音。
