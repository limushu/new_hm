## 不擅自扩展

不接入云端、团队服务、AI、法律期限自动计算或付费服务。不更改个人工作区数据；使用隔离目录验证。恢复覆盖与彻底删除必须由产品界面内明确操作确认。未验收的平台和未完成的功能如实记录。

2026-10-18 最新决策：以安装模式为正式分发方式，默认用户应用数据目录；实现用户确认后的签名在线更新，保留业务数据。历史绿色包仅保留归档，不作为 v1.0 默认交付。

验证记录：22 项 Rust 核心、15 项前端工具、31 项界面流程通过；正式 HTTPS 桌面构建完成文件、PDF、模拟录音、联系人/收支、备份恢复与重启检查。真实设备及其他平台边界见 [验收说明](v1.0-acceptance.md)。

交付记录：[Windows 1.0.0 Release](https://github.com/limushu/new_hm/releases/tag/v1.0.0)。公开资产重新下载校验全部 SHA-256，并验证安装包签名与受保护版本、篡改拒绝。正式桌面客户端读取线上清单返回无更新（当前版本即最新）。不冒充已在不同电脑完成从旧版安装至新版的系统级升级验收。

远程检查：应用源码提交 4612200 的 frontend、rust-core、windows-app 三项全部成功；版本标签触发的重复检查与重复发布构建已取消，保留经过校验的公开资产。后续 CI 只检查分支推送，版本发布工作流保留标签入口并避免覆盖已发布同版本。
