# Windows 0.1.4 预览版试用说明

此版本用于验证第一条真实的本地办案流程，适合用虚构数据试用和收集反馈，尚非完整产品。

## 程序与安装包

免安装绿色 ZIP 的启动、数据位置、携带与升级方式见[绿色版说明](portable-release.md)。绿色版为独立工作区，不自动复制安装版数据。

本机产物统一放在仓库的 `artifacts/windows/`，并保留 SHA-256 清单。安装包文件名含 `setup`；单文件 `.exe` 可直接运行。开发构建用 `preview` 标记，优化后的发布构建用 `release-preview` 标记。构建原文件在 `target/debug/`、`target/release/` 及其 `bundle/nsis/` 下。

可以把安装包发给其他 Windows 用户试用。接收方不需要 Node、npm、Rust 或源码，需要可用的 WebView2 运行时；安装器会按配置检查或安装运行时。目前仅在本机 Windows 11 x64 做了启动检查，其他 Windows 版本和 CPU 架构尚未验收。当前尚未做代码签名。

安装包只包含应用和前端静态资源，不包含开发者或试用者的案件数据库、原型数据、测试数据及 `node_modules`。不要把个人应用数据目录作为程序包分发。

## 已实现

1. 首页周/日时间表和月视图可直接创建、编辑和删除日程；支持小月历定位、全天、起止时间、跨日、地点、备注及重叠排版。新日程不预选案件，用户可主动关联或取消。有截止日期的案件待办自动呈现，无日期待办可展开。
2. 按未开始、进行中、已结案查看和搜索案件；支持跨列拖拽保存状态、触屏横向拖动和键盘移动，失败回到原列。
3. Notion 式右侧页内新建，名称唯一必填，默认民商事诉讼；空白草稿关闭取消，重复提交不重复建案。
4. 民商事案件默认一审；可以新增/切换二审、再审、执行，分别记录阶段、案号、法院与法官。
5. 添加待办、可选截止日期、勾选完成；添加文字工作记录。
6. 数据写入本地 SQLite，退出重开仍保留。
7. 案件移入回收站与恢复，程序、待办和记录保留。

## 尚未完成

正式材料复制归档与预览、录音、系统通知提醒、重复日程、拖动改期、联系人和关系图、收支、自动备份恢复、系统托盘、开机启动、自定义状态与完整阶段管理。界面的入口或说明不代表这些功能已实现。Android、iOS 和 macOS 安装包尚未构建验证。

当前关闭应用窗口会退出，提醒尚未接入；请勿把它当作已经具备期限提醒的正式办案软件。数据备份功能未完成，试用请使用虚构数据。

## 数据与后续升级

Windows 数据通常位于 `%LOCALAPPDATA%\com.limushu.hm\workspace.sqlite3`；同一 Windows 用户下的独立程序与安装版共用该目录。工作目录中没有数据库是正常的。文件可能伴随 SQLite 的 WAL/SHM 文件，不能仅复制正在运行中的主文件当作可靠备份。

不同用户或不同电脑各自保存本地数据，本版本没有云同步。软件升级不自动迁移到其他设备；数据库迁移版本会拒绝旧程序打开更高版本数据库。

0.1.1 首次启动会自动将数据库升级到版本 2，并保留 0.1.0 的案件及相关信息。升级后不要再用 0.1.0 打开同一数据库；旧版会拒绝打开。程序名称与数据目录保持一致。日期和时间按本地时间保存，当前不提供跨时区转换。

## 建议验证的流程

新建一个虚构案件 → 填写一审案号 → 新增二审 → 切回一审检查原案号 → 添加待办和记录 → 退出重开 → 检查数据 → 将案件移入回收站 → 恢复。

日历：日期格中的“+”（或双击空白处）→ 输入日程名称、时间 → 保存；不关联案件即为个人日程。点击条目可修改，删除需再次确认。可切换“全部 / 日程 / 待办”；条目过多时点击“还有 N 项”查看当天详情。全天日程的结束日期也计入安排。

反馈时说明操作步骤、期望结果和实际结果；截图前隐藏个人案件和当事人信息。
