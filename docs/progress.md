# 项目进度

更新日期：2026 年 10 月 18 日（北京时间）。

## 当前阶段

已从界面原型进入正式研发，采用 Tauri 2 + React/TypeScript + Rust + SQLite。Windows x64 开发预览和优化发布构建均已成功，NSIS 安装包已生成。正式应用和独立 HTML 原型分别保留。

0.1.1 已完成日历交互优化，Windows 优化发布安装包已构建成功。数据库增加独立日程表，从版本 1 自动迁移至 2，旧案件、程序、待办及工作记录保留；通知提醒尚未实现。

0.1.2 增加桌面默认周时间表、手机默认日视图、左侧小月历及日/周/月切换；关联案件由用户主动选择。按最新评审统一所有日程卡片为中性深灰弱底色、细边线和一致字体，不按是否关联案件使用不同颜色。重叠安排继续支持，等宽并排、窄列优先保留标题，不新增优先级字段。Windows 绿色包将业务数据与 WebView 缓存保存在 EXE 旁的 data/。

0.1.4 继续打磨案件看板，暂缓材料模块接入：状态列采用轻量底色、圆角标签和标题优先的卡片；跨列拖拽即时反馈并保存状态，支持触屏、键盘和取消，保存失败回到原列。只修改状态，不覆盖名称、类型、当前程序。数据库仍为版本 2。

## 已落实的产品约束

0.1.3 当前修订：点击半小时格默认创建半小时；卡片统一改为暗蓝底（#162D46）与蓝色（#295A8C）细侧边；当前时间线带时间标记、按分钟更新、恢复窗口时刷新，初次进入及点击“今天”定位当前时段；可选关联改为“＋ 关联案件”与搜索选择，选中后支持“×”取消。数据库版本仍为 2。

- 面向独立执业律师；Windows 优先，后续 macOS、Android、iOS。本地优先、离线可用、无需登录。
- 案件 → 办理程序 → 阶段；各程序的信息保留，程序结束不等于案件结案。
- 保留概览、材料、案件信息、收支四个固定入口。
- Notion 式右侧页内新建，仅名称必填；有效名称提交、空白草稿取消，可展开完整案件工作区。
- 保留 DESIGN-NOTION-COLOR 和 DESIGN-NOTION-DETAIL：配色、圆角、字体、图标以后统一打磨，当前为暂定基线。
- 同步、团队服务、AI 暂不实现；备份保持简单，不再深入展开方案讨论。
