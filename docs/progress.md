# 项目进度

更新于 2026-10-18（北京时间），当前版本 1.0.1，Windows x64 为首个验收平台。

## 已完成

- 案件侧页新建、状态看板拖拽、自定义列；办理程序、默认/自定义阶段、排序与跳过、事件历史及原案关联。
- 材料复制归档与拖入、同名编号、文件夹、程序归属、重命名/移动/导出/回收站；PDF/图片/音频预览，Office 打开归档副本。
- 案件录音、暂停继续、保存与播放；工作记录修改、附件及回收恢复。
- 联系对象管理、案件身份、法院/法官按程序关联、双向案件列表、直接关系图。
- 整数分收支、约定律师费、已收/待收、支出凭证、待报销/已报销。
- 日/周/月时间表、半小时创建、可选加号关联、重叠统一排版、当前时间线；提醒选择、通知入口、后台系统通知、托盘、可选登录启动。
- 全局名称搜索、虚构示例可选；完整备份、每天保留 7 份、校验恢复、恢复前副本及恢复中断保护。
- 安装模式交付、签名升级包、设置中由用户确认更新、更新前备份；CI 和版本发布工作流。

## 已验证

本地 Windows 的 22 项 Rust 核心集成测试、15 项前端工具测试、31 项界面流程通过。包含旧版本 1/2 迁移前副本、阶段保留、材料边界、同名保护、精确金额、联系人身份隔离、回收站、备份哈希/恢复/保留 7 份、中断恢复、提醒去重，以及看板触屏/键盘拖拽、日历和新模块流程。

Windows 正式发布构建以隔离虚构数据验证 HTTPS 应用协议、PDF 离线 worker、模拟麦克风录音与中文二进制保存、原始文件保护、SQLite 备份恢复及重启。安装包升级签名、受保护版本及篡改拒绝验证通过。原生流程脚本位于 tests/native；不要在个人资料目录运行测试，脚本创建专属 .local 工作区且只停止自己启动的进程。

[1.0.0 安装包已发布](https://github.com/limushu/new_hm/releases/tag/v1.0.0)，约 5.64 MiB。公开安装包及清单重新下载后的全部哈希和签名验证通过；正式桌面客户端成功读取线上更新清单，识别当前版本即最新。[GitHub 远程检查](https://github.com/limushu/new_hm/actions/runs/39053084969)的前端、Rust 核心、Windows 桌面编译全部通过（应用源码提交 4612200）。具体操作及设备验证边界见[1.0 使用与验收](v1.0-acceptance.md)。

## 1.0.2 案笺与交互完善

- 用户选定“案笺”名称，折页案卷图标用于侧栏、窗口、托盘和安装包。沿用旧安装注册表、自启动项、应用标识与数据位置；仅迁移指向本安装目录的旧快捷方式。
- 普通菜单与对象搜索菜单统一深灰圆角，支持键盘与顶层弹窗；字重收敛至 400/500/600。日期组件统一用于待办、日程、程序事件和收支，整块点选、手输、今天/清除及日期校验。
- 对象先展示详情，关系可独立浏览；删除会在事务中解除关联并保留案件历史文字，不因仍有关联而拒绝删除。新增防止旧文字回填重新生成已删除对象的回归。
- 案件侧页明确删除，看板拖入回收区、撤销、键盘删除和恢复。待办使用小型编辑弹窗。
- 弹窗通过 portal 独立挂载，修复详情中再打开编辑/删除弹窗导致嵌套表单并触发页面导航的问题；取消子弹窗不会关闭父弹窗。
- 28 项 Rust、17 项前端逻辑、39 项界面流程均已验证；格式、类型、文档链接及核心/桌面 Clippy 通过。
- 1.0.2 签名 NSIS 构建通过；在隔离虚构工作区完成原生菜单/待办日期、对象资料/删除、PDF、模拟录音、精确收支、完整备份恢复与重启验收。未读取个人数据、未关闭用户旧版应用。尚未在另一台干净机器验证安装或跨版本覆盖升级。
