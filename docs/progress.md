## 1.1.0 案件全貌与并行办理

- 按用户确认，一个委托或争议使用一个档案，内部多个程序可并行，当前关注与正在浏览分开；支持明确的前序关系、程序办结/恢复及循环校验。
- 全部程序节点常驻顶部；概览汇总摘要、关注阶段、参与人、待办、同源案件日程和材料分布，自动阶段历史折叠。材料的案件共用/程序入口与归档目标明确显示。
- 案件 #标签候选持久化，收支分类环图与律师费进度，统一字体语义变量与书面映射规范；AJ 品牌图标并显式配置窗口、程序资源、安装器快捷方式。
- Rust 后台查新版、侧栏提示、确认安装；可配置 HTTPS 优先更新源及 GitHub 回退。本地镜像准备脚本保留安装包签名并改写下载地址；实际 GitLab 或国内镜像地址尚未提供，尚未部署镜像。
- 数据版本 5，旧库迁移前备份，不推测旧程序前序，不重复回填已删除对象。
- 32 项 Rust 核心、17 项前端逻辑、47 项界面流程通过；覆盖程序并行与关注、循环拒绝、标签持久化、同源日程、收支图、材料入口、升级确认，以及原有功能回归。类型、格式、文档链接与 Rust 核心/桌面 Clippy 通过。
- 1.1.0 最终签名包在隔离工作区完成 HTTPS 生产协议、三程序与关注隔离、标签、同源日程编辑、PDF、模拟录音、对象、收支、备份恢复与重启验收，页面错误为空。Windows 分别读取得到 exe 资源、ICON_SMALL 与 ICON_BIG；中文实际字体为 Microsoft YaHei UI。
- [公开 1.1.0](https://github.com/limushu/new_hm/releases/tag/v1.1.0)安装包约 5.69 MiB；5 项公开资产重新下载后与本地逐项 SHA-256 相同，升级签名、受保护版本与篡改拒绝校验通过。隔离的原始 1.0.2 客户端成功检测到线上 1.1.0，没有实际执行安装或触碰个人数据。
- 应用源码 e3afd6286ae724f8336ee0dd91ca4ab62a02ae1a 的[三项远程 CI](https://github.com/limushu/new_hm/actions/runs/39081847794)全部通过。手动上传并验收正式包后，取消同标签触发的重复发布构建，保留已校验资产。实际跨电脑安装及真实设备验收仍由用户完成。
- [原生案件概览](design/current/case-overview-app-1.1.0.png)与[原生程序详情](design/current/case-programs-app-1.1.0.png)使用全新隔离的虚构数据。GitLab/国内镜像包准备工具已本地验证，示例域名只用于验证清单改写，没有网络发布。

- 用户选定“案笺”名称，折页案卷图标用于侧栏、窗口、托盘和安装包。沿用旧安装注册表、自启动项、应用标识与数据位置；仅迁移指向本安装目录的旧快捷方式。
