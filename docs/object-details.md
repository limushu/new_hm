# 一个对象，一张详情

## 交互

时间轴条目进入统一对象详情。上方是名称、类型与时间，内容区按对象类型展示录音播放器、文档预览、费用金额、工作记录或节点说明；下方保留标签、自定义属性与关联对象。录音不自动播放，不再自动叠加预览弹窗。关闭详情直接回到原时间轴。

省略号打开操作菜单，提供查看详情、编辑信息、标为重要等常用动作。材料和工作记录可经明确确认移至回收站；没有对应回收能力的对象不显示该选项。标为重要是即时操作，标签与重要程度的批量编辑在同一详情中明确保存或取消。保存失败保留草稿，取消不提交。

内容编辑和明确选择的全屏预览替换主详情，不在下面隐藏另一张详情。全屏预览的退出入口标为“返回详情”；关联对象在当前容器内切换，提供“返回上一对象”。播放器离开、对象切换或进入编辑时停止播放。

自定义属性仍使用已有的名称、类型、内容一次编辑流程；关系编辑仍支持选择已有对象或创建关联对象。类型专属编辑继续沿用原模块的业务校验，元数据操作保留其他已有属性。

当前文本/Markdown 内容可预览、归档、导出；本次不新增覆盖原文件的正文写入接口。原有 `DocumentEditorProvider` 保留修订检查约定，未来可注册对应编辑器。旧办理流程节点提供名称编辑，其他专业字段继续使用其原业务入口或自定义属性。

## 分层

- `case-system/presentation.ts` 定义对象的 `content`、`editor` 和 `expanded` 适配器，各类型在 `resourcePresentations.tsx` 注册。业务存储、时间轴投影与展示分离。
- `ObjectInspector` 管理详情、信息编辑、内容编辑和全屏状态；一次只挂载一个主要详情/编辑界面。关联导航只改变当前对象和返回历史。
- `ObjectActionMenu` 共用于时间轴与详情。只提供受支持的操作，回收复用已有 `trash_item` 命令。
- `MaterialContent` 复用音频、视频、文本、图片和 PDF 的加载与渲染。材料页独立预览和对象内嵌预览共用此组件；仅明确打开 PDF 时加载 PDF.js。
- `ResourceRelations` 与 `ObjectProperties` 保留已有对象引用、属性与关系接口；不新建材料副本，不改变 schema 9。
