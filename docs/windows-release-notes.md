# 案笺 1.8.9 · Windows 测试版

Windows x64，与 iOS 1.8.9 共用业务核心和界面。相对于上次 Windows 1.4.3：

- 案件以时间轴组织节点、记录、待办、日程、材料与收支；人员和机构集中查看。
- 对象支持重要程度、标签、自定义属性和相互关联；属性名称、类型、内容一次填写。
- 添加关联先选查找范围和对象类型，再选择已有对象或新建；取消新建保留关联草稿。
- 统一页头、按钮、浮层和自适应强调色；收紧案件卡片、日期栏与详情比例。
- 标签和状态支持连续修改，保留未确认的名称草稿；修复详情重绘和长标题抖动。
- 沿用 Windows 本地材料导入/导出、录音、费用图表、备份恢复、系统通知、托盘和签名升级。

旧安装版可覆盖安装。数据库由版本 7 升级到 9，升级前自动保留原数据库；建议先在旧版设置中创建完整备份。升级后不要用旧版打开新版数据库。

此测试包尚未接入 Windows 账号登录、iCloud 自动同步、语音转文字和系统日历。现有 iOS 专属驱动不代表 Windows 也支持这些功能；本机案件、完整备份与恢复可离线使用。

安装与验收方法见同包 `README.zh-CN.md`。升级包有来源校验签名；Windows 发布者代码签名尚未配置。
