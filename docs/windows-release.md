# Windows 1.8.9 测试版

本版将最新共用案件功能带到 Windows x64。程序不要求账号，业务数据保存在本机；[本次改动](windows-release-notes.md)与 [iOS 1.8.9](app-store/README.md)共用对象、属性、关系和界面代码。系统能力仍通过[平台驱动](design/platform-driver-map.md)装配。

## 安装与升级

运行 `hm-workspace_1.8.9_windows-x64-setup.exe`，安装到当前 Windows 用户。需要 Microsoft Edge WebView2；缺少时安装器会引导安装，首次安装可能需要联网。无需 Node、Rust 或源码。

旧安装版可覆盖安装，准确数据位置见“设置 → 本地数据”，通常为 `%LOCALAPPDATA%\com.limushu.hm\`。升级前建议在旧版设置中创建完整备份。1.4.3 的 schema 7 会升级到 schema 9，程序会先在 `migration-backups/` 保存原数据库，再事务迁移。保留案件、流程、人员、待办、收支和材料，升级后不要用旧版打开新版数据库。

安装包不含开发者数据。升级包使用现有升级公钥验证来源，Windows 发布者代码签名尚未配置；两者属于不同机制。当前关闭窗口可按设置驻留托盘，明确退出后停止后台工作。

## 建议验收

1. 从 1.4.3 升级，检查原案件、流程、待办、人员、收支、材料和日程；查看迁移前副本。
2. 连续添加两个标签、修改案件状态，确认未保存的案件名称没有跟着保存。
3. 在节点详情一次填写属性名称、类型和内容；添加关联时选择范围、类型、已有对象，或新建对象。取消新建后，关联选择和说明应保留。
4. 导入一个虚构文件，查看材料与时间轴；试听实际麦克风录音。费用页核对金额与图表。
5. 在深浅主题和窄窗口切换四个案件标签，检查正文、页头和底部操作。切换强调色并重启，核对偏好保留。
6. 创建完整备份，增删虚构内容后恢复并重启，检查自定义属性、关联、材料及原文件完整。
7. 新建未来日程并设置提醒，允许通知；核对应用运行期间、托盘驻留、退出与唤醒时的表现。

自动化使用隔离工作区和虚构数据，验证原生 WebView2/IPC/SQLite 与桌面窗口。通知真实送达、个人文件提供器、实际麦克风、其他 Windows 设备仍需实机核对。

## 构建

GitHub 的 `Windows release` 工作流完成核心测试、发布构建、升级签名验证和原生启动/持久化检查，成功后提供 `windows-release` 安装包及 `windows-verification` 截图/报告。候选构建也可在产品源码不变时通过独立 `Windows candidate native checks` 复验，先校验来源、EXE 哈希和升级签名，再执行原生检查。手动触发仅生成测试产物，不变更现有稳定更新入口；发布版本标签仍沿用原有流程。
