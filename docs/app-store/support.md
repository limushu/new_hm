# 案笺使用与支持

案笺用于在设备上整理案件、日程、材料、录音与工作记录，无需注册或登录。

## 开始使用

1. 在「案件」页面点击「新建案件」，填写案件名称。
2. 点击「创建案件」保存名称，再按「脉络、材料、人员、费用」查看和整理内容。
3. 点击时间轴条目，在同一详情内查看内容、属性与关联；录音可在页内播放。省略号提供常用操作，编辑信息需保存或取消。
4. 从「创建」新增关键节点、文档、人物或收支，为节点添加属性并关联本案对象。
5. 在「材料」中点击「添加材料」选择文件，导入时复制归档，原文件保留。
6. PDF、图片和音频可在应用内预览；其他格式可以通过材料操作菜单导出副本。
7. 录音仅在点击开始后使用麦克风。iOS 锁屏、进入后台或系统音频中断会暂停录音。
8. 支持的 iOS 设备可在结束录音后点击「转成文字」，或从已有音频预览进入转写。原录音先保存，普通话与英语识别在设备内进行，文字可编辑后另存为关联材料。

## 数据与备份

案件和材料保存在设备的应用数据目录。本机自动备份不等同于设备外备份。iOS 可在「设置 → 备份与恢复」导出完整 ZIP 备份，通过系统「文件」保存到 iCloud 云盘或其他位置；从文件恢复时先校验、展示摘要并要求确认替换，当前数据会先保留恢复前副本。云盘上传由系统处理，这不是自动同步。备份未另设密码加密，请妥善保管。卸载会移除本机应用数据，已有外部备份与系统设备备份需要自行管理。

## 故障排查

- 无法录音：检查系统设置中的麦克风权限，回到应用前台后重试。
- 无法转写：检查系统语音识别权限及所选语言是否支持设备内识别，转写时保持应用在前台。设备不支持时不会改用云端；识别文字请对照原录音核对。中断后可保存已识别部分。
- 无法读取文件：确认你选择的文件已经下载，且文件提供器允许访问。
- 导出未完成：检查目标位置是否可写，重新选择保存位置。
- 不支持预览的格式：从材料操作菜单导出副本，再用支持此格式的应用打开。
