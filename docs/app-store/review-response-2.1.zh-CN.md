# Guideline 2.1 补充资料与真机演示

反馈对应旧构建 **1.4.3（11.1）**。用户已决定改用最新主分支的 **1.7.7（25.1）** 重提。该候选已签名并成功上传，检查与产物核对结果见发布准备记录；Apple 处理完成后才能选择构建。新的 App Review 提交尚未执行。

## 要补充的内容

英文审核备注在 [metadata.zh-CN.json](metadata.zh-CN.json) 的 `reviewNotes` 字段，打包后为 `text/review-notes-en.txt`。已按苹果要求覆盖六项：真机演示、用途和受众、使用说明、外部服务、地区差异、受监管服务及内容权利。

提交前必须把以下占位符换成真实资料，并读一遍第一项，确保描述与实际视频一致：

- `[PHYSICAL_DEVICE_VIDEO_URL]`：审核期间持续可用、审核员无需额外登录即可访问的视频链接；如通过审核沟通附上视频，也在备注中注明附件文件名和所在消息。
- `[DEVICE_MODEL]`：实际录屏设备，例如你使用的 iPhone 型号。
- `[IOS_VERSION]`：实际系统版本。在「设置 → 通用 → 软件更新」确认最新公开版本，在「关于本机」核对版本号。

审核 Notes 最多按 4000 字符准备，替换长视频 URL 后需重新检查。当前文字是草稿，不可原样保留占位符提交。不填写未经完成的真机测试结论，不宣称已在所有设备上验证。

## 真机录屏脚本

建议约 3–5 分钟，正常速度，竖屏、画面文字可读。时长为演示建议，不是苹果规定。

录制前，在 TestFlight 安装 **1.7.7（25.1）**；用虚构数据演示，关闭会泄露私人信息的通知。使用 iPhone 自带的屏幕录制，先返回主屏幕，再开始录制。

| 顺序 | 演示操作 | 让审核员看到什么 |
| --- | --- | --- |
| 1 | 从主屏幕点击「案笺」图标启动 | 实际应用启动，无注册或登录障碍 |
| 2 | 「案件 → 新建案件」，输入「审核演示 · 借款资料整理」，点击「创建案件」 | 面向个人的案件整理工作区 |
| 3 | 「创建 → 关键节点」，新建「一审」，保存并打开节点 | 节点、属性和关联对象的实际用法；可加文本属性「目标」并填写「核对示例证据」 |
| 4 | 「材料 → 添加材料」，从系统文件选择器导入 `sample-case-notes.txt`，点开阅读 | 本地文件导入、阅读与归档。下方提供虚构样例 |
| 5 | 点击「录音」，再点「开始录音」，按实际提示授权；说一句虚构演示内容后结束，点「转成文字」，按提示授权，待完成后编辑并保存转写稿 | 原录音先保存，支持设备内普通话或英语转写，文字独立保存并关联原录音；若设备模型不支持，应如实展示说明，再演示保存与播放原录音 |
| 6 | 「人员 → 添加人员或机构」，先选「个人」，再选「新建个人」，填写「虚构当事人甲」并点击「新建并添加」；也可选法院并复用已有档案 | 人员并非聊天或公开社交功能，而是用户自己的案件记录 |
| 7 | 「费用 → 记一笔」，填写一笔虚构的差旅费 100.00 元，保存 | 收支记录和分类图；收入、支出切换后能看到相应记录 |
| 8 | 返回「脉络」，查看刚创建的节点、材料与收支 | 同一案件中的工作内容如何聚合 |
| 9 | 「设置 → 隐私政策」，展示应用版本（设置页底部） | 数据处理说明与本次提交版本 |

新建文档也可补充演示：「创建 → 新建文档」，输入虚构内容并保存。选用流程须与设备中实际按钮文案一致。

使用应用的系统麦克风录一段演示音频时，iOS 屏幕录制可能与应用争用麦克风。屏幕录制的旁白麦克风可先关闭，重点展示应用内录音操作和保存、播放结果；真机先完整试走一次。如该设备出现录音冲突，应先解决并重新录制正常的演示，不用失败状态充当功能展示。

可先做一次不录屏的真机验收：启动、案件与节点保存、文件导入/阅读、录音保存/播放、设备内转写与文字保存、人员、收支、重启后数据保留。记录实际设备和系统信息。iPad 模拟器素材不代表已经完成 iPad 真机验收；如继续声明支持 iPad，应按实际支持范围安排验证。

## 审核样例文件

- [sample-case-notes.txt](review-samples/sample-case-notes.txt)：供导入和阅读的虚构工作记录。
- [sample-expense-note.txt](review-samples/sample-expense-note.txt)：供关联费用的虚构说明，不是发票或付款凭证。

打包后位于 `review-samples/`。可以先把文件保存到 iPhone 的「文件」中。审核员也可使用自己的文件；应用没有必须下载的外部数据集、激活码或测试账户。

## 后台重提顺序

1. 在 App Store Connect 的待审版本中，把商店版本更新为 **1.7.7**，选择对应 **25.1** 构建。确认不再选中旧的 11.1；如后台当前状态锁定编辑，按实际状态处理版本记录后再继续。
2. 替换成最新应用的商店截图。`screenshots/` 中是实际应用的模拟器截图；它们可用于商店展示，不作为这次苹果明确要求的真机录屏。
3. 在「App 审核信息 → 备注（Notes）」粘贴已补全视频、设备与系统资料的英文说明。无需登录，将“需要登录”按实际情况关闭；保留真实审核联系人。
4. 在这次审核沟通中说明已改交 1.7.7（25.1），六项资料和视频已写入 Notes，然后重新提交审核。不要只回复一句“已解决”而未填写 Notes。
5. 保持用户已选择的免费和手动发布方式；审核通过与手动对外发布是两个动作。

2.1 补充信息不等于中国大陆备案要求已经核实。首发地区与备案适用性仍按 [发布准备记录](README.md) 中的独立事项处理，不编造备案号、律师执业证或其他资质。
