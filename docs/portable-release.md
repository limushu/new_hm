# 律师工作台 0.1.4 绿色预览版

完整解压 ZIP 后，双击文件夹里的“律师工作台.exe”。无需运行安装程序，不需要管理员权限、Node 或 Rust。当前适用于 Windows x64，需要系统已有 Microsoft WebView2 运行时；缺少时需先安装该运行时。不要直接在压缩包中启动。

程序旁的 `.portable` 文件用于启用绿色模式，请保留。首次运行会在同一目录创建 `data/`，其中 `workspace.sqlite3` 保存业务数据，`webview/` 保存界面缓存。设置页会显示当前模式和数据目录。目录无法写入时会报错，不会自动改用其他数据位置。

携带到其他位置或电脑时：完全退出程序后，复制整个文件夹（包含 `.portable` 和 `data`）。升级时退出程序，替换 EXE 并保留原 `.portable` 和 `data`；不要用空白目录覆盖数据目录。绿色版中的业务数据不自动与安装版同步。

首次打开绿色包是空工作区，安装版原数据不会自动复制，也不会被删除。如果需要沿用旧数据：先完全退出所有版本，在旧版设置页找到数据目录，将其中的 `workspace.sqlite3` 及仍存在的 `workspace.sqlite3-wal`、`workspace.sqlite3-shm` 一起复制到绿色版的 `data/`；仅在目标尚无业务数据时执行，保留旧目录作为副本。不要在程序运行时复制数据库。

这是功能尚未完整的预览版。当前包含案件、办理程序、待办、工作记录及独立日程；日历支持周/日时间表、月视图、时间段新建、重叠安排并排展示。新日程默认不关联案件，用户主动选择或取消关联。材料归档、系统通知、备份恢复等尚未实现，不应依赖它发出期限提醒。

日程卡片统一使用暗蓝底（#162D46）、蓝色（#295A8C）细侧边和一致字体，不按案件关联状态标不同颜色。重叠安排均匀并排，窄列隐藏地点等次要信息；侧边色属于统一样式，不表示优先级。点击半小时格默认创建半小时，时长可再修改。

今天的时间表显示红色当前时间线与时间标记，按分钟更新；打开本周/今天会定位到当前时段，点击“今天”可重新定位。其他日期不显示当前时间线。关联入口为“＋ 关联案件”，点击后可搜索选择，已关联时显示案件名并可用“×”取消。

案件看板支持跨状态列拖拽，松手后保存；拖出看板或 Escape 取消，保存失败恢复原列。也可在卡片上按空格拿起、左右方向键选列、回车放下。移动只改变案件状态，办理程序与其他信息保持不变。

程序尚未签名，Windows 可能提示未知发布者。只分发原始 ZIP；自己使用后的 `data/` 可能含有个人案件，不要当作试用包发送给别人。
