# 律师个人工作平台

面向中国大陆二三线城市小型律所中独立执业律师的本地工作软件，重点是简单易用的案件管理、日程安排和资料归档。产品名称尚未确定，“律案”为设计稿占位名。

第一版优先 Windows，后续目标为 macOS、iOS 和 Android。后端主要采用 Rust，前端和存储方案尚未选定。
